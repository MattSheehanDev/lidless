Small on purpose

Everything it does fits in one menu.

⏱

Timed or indefinite

From 10 minutes to 12 hours, a custom number of minutes, or until you turn it off. A live countdown shows what's left.

🌙

Let the display sleep

Optionally let the screen turn off while the Mac keeps working, which is good for long downloads and builds.

🔋

Cleans up after itself

Uses the same power-management API as caffeinate. Sessions end on time, and quitting always releases the hold.

🚀

Launch at login

Registers as a login item so it's always waiting in your menu bar.

⌨️

Scriptable

Start a session from the terminal with --minutes 45 or --indefinite.

🪶

No Dock icon, no fuss

A native AppKit menu bar agent with no dependencies, no admin rights, and no background daemons.

Install

Free download for macOS 14 or later, on Apple Silicon and Intel.

  1. Download Lidless.zip and unzip it.
  2. Move Lidless.app to your Applications folder and open it.
  3. macOS blocks it the first time because it isn't notarized. Open System Settings → Privacy & Security, scroll down, and click Open Anyway.

Or from Terminal

curl -L -o /tmp/Lidless.zip \
  https://github.com/MattSheehanDev/lidless/releases/latest/download/Lidless.zip
ditto -x -k /tmp/Lidless.zip /Applications
xattr -dr com.apple.quarantine /Applications/Lidless.app
open /Applications/Lidless.app

Build from source

# xcode-select --install  (if needed)
git clone https://github.com/MattSheehanDev/lidless
cd lidless
make install

Start a session from the terminal

open /Applications/Lidless.app --args --minutes 45
open /Applications/Lidless.app --args --indefinite
Heads up: closing the lid still sleeps the Mac unless an external display and power are connected (clamshell mode). All versions are on the Releases page.
